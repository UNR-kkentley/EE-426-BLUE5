What the DAC timer actually controls

The software produces sample values; a hardware timer sets how often the DAC outputs the next voltage. The rate below is adjustable for demonstration.

The timer determines timing. The DAC determines voltage. A DMA channel can transfer precomputed samples without asking the CPU to write each value.
